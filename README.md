# Speech Emotion Recognition

## Project Overview
This project uses machine learning to classify emotions
from speech audio recordings using the RAVDESS dataset.

## Technologies Used
- Python
- Librosa
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

## Dataset
RAVDESS Speech Emotion Dataset

Total Audio Samples: 1440

## Audio Feature Extraction
MFCC (Mel-Frequency Cepstral Coefficients)

## Machine Learning Algorithm
Random Forest Classifier

## Model Performance
Test Accuracy: 59.72%

## Output Files
- audio_features.csv
- results_summary.txt
- confusion_matrix.png
- accuracy.txt
- emotion_model.pkl
- scaler.pkl

## How to Run
Install the required packages and execute:

python main.py

## Disclaimer
This is an educational project. Predicted emotions
should not be treated as reliable psychological assessments.
